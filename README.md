# Consumer Complaint Letter Drafter

Local-first CLI that drafts consumer complaint, warranty, and small-claims
demand letters using a language model served through an OpenAI-compatible
endpoint (Ollama by default).

Built and maintained by **Asdale Dynamics, LLC** — beginner-friendly AI
education, books, guides, and practical tools. Learn more at
[dylanasdale.github.io](https://dylanasdale.github.io) and in *The Massive AI
Manual*.

## What it does

- Drafts three kinds of letters:
  - **Consumer complaint** — a business messed up; you want it fixed.
  - **Warranty claim** — request repair, replacement, or refund under a warranty.
  - **Small-claims demand** — formal demand before filing in small-claims court.
- Talks to any OpenAI-compatible `/v1/chat/completions` endpoint; defaults to
  Ollama on `http://localhost:11434/v1`.
- Runs entirely local-first. No cloud account, no API key, no personal data
  leaves your machine unless you choose to send it.
- Prints the draft for you to review, edit, and send yourself. **This tool
  never sends a letter automatically.**

## Important: education only

Every draft includes this disclaimer:

> This letter was generated by an AI tool for EDUCATIONAL PURPOSES ONLY. It is
> NOT legal advice and does not create an attorney-client relationship. Review
> it carefully, edit it as needed, and consider consulting a qualified
> attorney or consumer-protection agency before sending.

## Install

```bash
git clone <this-repo>
cd consumer-complaint-letter-drafter-cli
python3 -m pip install -e .
```

This package has no third-party dependencies — it uses only the Python
standard library.

## Run

```bash
# Interactive draft (defaults to Ollama at localhost:11434/v1, model llama3.2)
consumer-complaint-drafter complaint

# Pick a different letter type, endpoint, or model
consumer-complaint-drafter warranty \
    --endpoint http://localhost:11434/v1 \
    --model llama3.2

# Save to a file instead of printing
consumer-complaint-drafter small-claims --output demand_letter.txt
```

You will be prompted for your name, address, the recipient, account numbers,
the problem, steps already taken, and your desired resolution. Skip anything
optional with Enter.

### With Ollama

```bash
ollama serve            # in one terminal, if not already running
ollama pull llama3.2
consumer-complaint-drafter complaint
```

## Tests
