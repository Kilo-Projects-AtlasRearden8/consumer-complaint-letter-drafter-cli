# STATUS

## What was built

A local-first Python CLI, `consumer-complaint-drafter`, that drafts three
kinds of consumer letters using a language model served through any
OpenAI-compatible `/v1/chat/completions` endpoint (Ollama by default):

- `complaint` — consumer complaint letter to a business
- `warranty` — warranty claim letter (repair / replacement / refund)
- `small-claims` — formal pre-filing demand letter for small-claims court

The user answers interactive prompts (name, addresses, account number,
product, problem, steps taken, desired resolution, response deadline), the
tool asks the model for a draft, then prints the draft plus an
education-only disclaimer. The draft can optionally be saved to a file with
`--output`. The tool never sends anything — sending is entirely manual.

## How to run

```bash
cd consumer-complaint-letter-drafter-cli
python3 -m pip install -e .        # or just run from the folder

# Interactive draft (default endpoint: Ollama at localhost:11434/v1)
consumer-complaint-drafter complaint
consumer-complaint-drafter warranty
consumer-complaint-drafter small-claims

# Custom endpoint/model, save to file
consumer-complaint-drafter complaint \
    --endpoint http://localhost:11434/v1 \
    --model llama3.2 \
    --output my_letter.txt
```

With Ollama:

```bash
ollama serve
ollama pull llama3.2
consumer-complaint-drafter complaint
```

Every draft ends with:

> This letter was generated by an AI tool for EDUCATIONAL PURPOSES ONLY. It is
> NOT legal advice ... This tool NEVER sends letters automatically.

## Verification results

- `python3 -m unittest discover -s tests -v`: **16/16 tests pass**.
  - `MockEndpointTests`: live local mock HTTP server returns a completion;
    client model fallback works.
  - `ClientErrorTests`: connection refused raises a friendly `EndpointError`.
  - `LetterPromptTests`: all three letter types build prompts with user facts;
    unknown type raises `ValueError`.
  - `DisclaimerTests`: disclaimer contains "EDUCATIONAL PURPOSES ONLY",
    "NOT legal advice", "NEVER sends letters automatically".
  - `CliParserTests` / `CollectDetailsTests` / `DraftLetterTests` /
    `MainTests`: CLI defaults, flags, file output, disclaimer in output,
    non-zero exit on endpoint failure.
- `python3 -m consumer_complaint_drafter.cli --help`: prints usage.
- End-to-end smoke test with no Ollama running: friendly connection error
  message, exit code 1.

A real model draft requires a running Ollama (or compatible) endpoint with a
model pulled; that runtime is not part of this repository.

## Known gaps

- Requires a locally running model endpoint (Ollama default) to generate
  drafts; the CLI gives a clear error message if none is reachable.
- Validation of user-supplied facts is minimal by design (the model is told
  not to invent facts); the user must review every draft before sending.
- No config file yet; endpoint/model/timeout are set via flags or environment
  defaults in code only.
- Not tested against a real Ollama instance in this environment (no model
  runtime available); verified with a local mock endpoint instead.
