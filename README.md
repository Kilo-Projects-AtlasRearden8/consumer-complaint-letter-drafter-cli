# Consumer Complaint Letter Drafter

A friendly, local-first command-line tool that helps you draft consumer
complaint, warranty, and small-claims demand letters using a local AI model.

Built by **Asdale Dynamics, LLC** — beginner-friendly AI education, books,
and practical tools. Learn more at [dylanasdale.github.io](https://dylanasdale.github.io)
and in *The Massive AI Manual*.

## Who this is for

You bought something, it didn't work, and you want to write a clear, firm,
polite letter to the company — but you're not sure where to start. This tool
drafts the letter for you. You review it, edit it, and send it yourself.

It handles three situations:

- **Consumer complaint** — a product or service let you down; you want it fixed.
- **Warranty claim** — request a repair, replacement, or refund under a warranty.
- **Small-claims demand** — a formal demand letter before filing in small-claims court.

## Education only — please read

Every letter this tool produces includes this disclaimer:

> This letter was generated by an AI tool for EDUCATIONAL PURPOSES ONLY. It is
> NOT legal advice, and it does not create an attorney-client relationship.
> Consumer-protection, warranty, and small-claims laws vary by state and by
> situation. Review this letter carefully, edit it as needed, and consider
> consulting a qualified attorney, legal-aid organization, or consumer-protection
> agency before you send it.

This tool **never sends a letter automatically**. It only writes a draft. You
decide whether to send it, and you send it yourself (by mail, email, or through
the company's portal).

## Install

You need Python 3.9 or newer. No extra packages are required — this tool uses
only the Python standard library.

```bash
git clone <this-repo>
cd consumer-complaint-letter-drafter-cli
python3 -m pip install -e .
```

That installs the `consumer-complaint-drafter` command.

## Run it, step by step

### 1. Start a local model (Ollama)

By default the tool talks to Ollama at `http://localhost:11434/v1`.

```bash
# In one terminal, start Ollama if it isn't running already
ollama serve

# Pull a small, capable model (you only need to do this once)
ollama pull llama3.2
```

You can point the tool at any OpenAI-compatible endpoint with `--endpoint`.

### 2. Draft a letter

```bash
consumer-complaint-drafter complaint
```

You'll be asked for your name, address, the company, what happened, what you've
already tried, and what resolution you want. Press Enter to skip anything
optional.

### 3. Review, edit, and send yourself

The tool prints the draft letter followed by the education disclaimer. Read it
carefully, make changes, and send it yourself. The tool does not send anything,
save anything to the internet, or require an API key.

### 4. Save a draft to a file (optional)

```bash
consumer-complaint-drafter warranty --output my_warranty_letter.txt
consumer-complaint-drafter small-claims --output demand_letter.txt
```

### Options

| Option | What it does | Default |
|--------|--------------|---------|
| `--endpoint` | Base URL of the OpenAI-compatible endpoint | `http://localhost:11434/v1` |
| `--model` | Model name to use | `llama3.2` |
| `--timeout` | Seconds to wait for a response | `60` |
| `--output` | Save the draft to this file instead of printing | (print only) |
| `type` | Letter type: `complaint`, `warranty`, or `small-claims` | (required) |

Example:

```bash
consumer-complaint-drafter small-claims \
    --endpoint http://localhost:11434/v1 \
    --model llama3.2 \
    --timeout 120 \
    --output demand_letter.txt
```

## What a draft looks like

Here's the shape of the letter the tool asks the model to write:

```
Your Name
Your Address
City, State ZIP

Date

Recipient Name
Recipient Address

Subject: ...

Dear [Recipient],

[Clear, respectful description of the problem and what you want]

Please respond by [date].

Sincerely,
[Your Name]
```

The model only uses the facts you provide — it won't invent dates, amounts, or
legal claims.

## Tests
